About the System

SETRUM — PLN Mobile Review Analyzer v2.0

Hierarchical Multi-Agent NLP system for automated analysis of PLN Mobile customer reviews.

Agent Pipeline
Orchestrator Agent: pipeline coordination
Agent 1 — Normalization: text preprocessing
Agent 2 — Sentiment: IndoBERT gate (negative only)
Agent 3 — Classifier: L1–L3 fine-tuned IndoBERT
Agent 4 — Escalation: L4–L5 zero-shot BART-MNLI
Tech Stack
Python 3.9+ + Flask
SQLite database
IndoBERT (local) + BART-MNLI zero-shot
google-play-scraper
Chart.js + vanilla JS dashboard
